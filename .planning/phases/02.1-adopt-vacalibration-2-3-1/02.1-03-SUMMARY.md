## Accomplishments

- PR #132 squash-merged as `eb3049e` after two CI-green runs (the second after the `/code-review` fixes). Its first deploy, run 34733336669, **failed** in the vacalibration install step: `dependencies 'rstan', 'patchwork', 'reshape2', 'LaplacesDemon' are not available`. `install.packages(repos = NULL)` resolves no dependencies, and those four had only ever reached the image transitively through `install.packages('vacalibration')` from CRAN. Fixed forward by PR #133 (`7f35d7d`): the four Imports are installed from `CRAN_SNAPSHOT` before the tarball step, and the pinning guard asserts that ordering (40 assertions, mutation-tested).
- Deploy run 34733552843 on `7f35d7d`: `check-changes`, `build-and-push`, `deploy` all `success`, read per job. The step "Verify backend package manifest (issue #123)" reported `success` on the first build of the fixed Dockerfile: the image's `/opt/package-manifest.csv` equals the committed file (135 rows, `vacalibration,2.3.1`, no `remotes` row). Build log: `* DONE (vacalibration)`, `seqcalib.stan` compiled in 1.1 s, `seqcalib_mmat.stan` in 1.0 s. `GET /api/health` → 200.
- Two acceptance jobs submitted through a logged-in admin session on dev (the API is login-only), read back via the results endpoint, the Results tab text, the job log and the CSV export.
